# 本地 Agent 权限运行环境：MVP 产品与 UX

状态：2026-09-19 确认的产品基线；本文描述目标行为，不代表安全机制均已实现。

## 定位与验收原则

面向本地 agent 的独立权限运行环境：账户由环境托管，agent 只获得用户明确授权、可撤销的操作能力。

整个 agent、插件、skills 和子进程位于受限区域；真实上游凭证留在区域外。身份校验、授权和 connector 位于可信区域。即使 agent 不遵守指令，也不能超出外部策略。隐藏凭证本身不足以阻止通过代理滥用账户。

读取的邮件、文件内容可能进入 agent 会话及云模型；凭证隔离不等于数据不出本机。权限界面必须显示真实数据去向。可信宿主、VM 管理员及网关不在 agent 隔离的防护对象内。

## 信息结构

- Agent：列表 → 聊天 / 连接与权限 / 工作文件 / 设置。
- 账户：全局连接、重新认证、断开；连接不自动授权任何 agent。
- 活动记录：按 agent、任务、资源检索请求、决策、执行结果。
- 环境状态：启动、停止全部 agent、资源设置；关闭窗口不等于停止任务。

## 01 首次启动

1. 欢迎页介绍运行位置与权限模型，主操作「创建本地运行环境」。
2. 展示真实估算的下载和磁盘需求，选择数据位置；CPU/内存提供默认值。
3. 下载 → 校验 → 初始化 → 启动。支持失败重试，不伪装成功。
4. 完成后显示空列表与「添加 agent」。以后自动启动环境；未完成任务不自动恢复执行。
5. 环境不可用时允许查看历史、配置。关闭窗口且有任务时询问后台继续或停止。

## 02 安装 agent

1. MVP 仅提供已适配 Pi，展示来源、实际版本和占用；后续适配 Hermes。
2. 命名，创建独立身份、工作空间及会话存储。
3. 选择或新增模型连接。登录/凭证录入走可信 UI，不经过聊天或 agent。
4. 安装进度、失败原因和重试；受控安装网络权限不延续到运行期。
5. 安装完成可跳过资源配置直接聊天。默认只有自身工作空间，不继承其他 agent 的资源。

任意镜像/安装命令、任意 agent 兼容性、多 agent 同时执行不作为第一版承诺。

## 03 目录授权

入口：agent → 连接与权限 → 本地目录 → 添加目录。

1. 可信桌面端打开系统选择器，用户选目录；agent 提供路径不是授权证据。
2. 确认页显示规范化真实路径、agent 内别名、包含子目录、模型数据去向。
3. 默认只读；读写明确包含创建、覆盖、移动和删除，直接影响本地文件。
4. 权限页新增默认持续至撤销；任务内新增默认仅本任务。每次均显示有效期。
5. 检测重复/父子重叠授权并拒绝新增，指向已有授权。别名不能冲突。
6. 持久化后安装实际访问边界，收到生效确认才显示「已开放」。

建议路径：原始资料目录只读，结果目录读写。读写不是「写入时再审批」。不提供未经实现的回滚承诺。

实现必须防止符号链接、路径替换、目录重命名等绕过。已授权路径被替换时不得默默授权新对象；目录离线或失效需提示重新选择。宿主 home 根目录、系统目录和凭证目录采用保守的禁止/限制选择规则，具体平台规则待文件访问模块设计确定。

| 状态 | UI | 下一步 |
|---|---|---|
| 待生效 | 正在开放 | 等待宿主访问层确认 |
| 有效 | 只读/读写、有效期 | 修改或撤销 |
| 目录不可用 | 不可访问、原因 | 重新选择或移除 |
| 撤销中 | 正在阻断访问 | 暂停相关执行 |
| 已撤销 | 记录保留 | 新授权才能再次访问 |

## 04 账户连接与授权

1. 全局账户或 agent 权限页「连接 Gmail」→ 系统浏览器 OAuth → 校验回调 → 返回应用。
2. 展示实际账户与 OAuth scopes；认证取消或失败时不创建有效连接。
3. 连接成功显示「已连接，当前 agent 尚未授权」。
4. 每个 agent 单独选择：每任务询问（默认）、限定范围持续读取、禁止。
5. 第一版只读。持续读取必须配置可执行的范围，不提供默认无限访问。
6. 模型连接与 Gmail 独立管理。上游授权过期进入「需要重新认证」，禁止无提示回退。

断开账户影响全部 agent：展示受影响实例，撤销本地 grants、终止待执行调用、移除本地凭证。上游 token 撤销失败应独立显示，不能把删除本地连接当作上游已撤销。

## 05 任务与审批

示例：「结合项目资料和今天的邮件，整理进展报告，保存到整理结果。」

1. 接受 prompt，分配 task ID；检查资源权限。
2. 已有有效目录权限直接使用；缺少 Gmail grant 时暂停对应步骤。
3. 可信层生成授权卡：agent、实际账户、操作、具体范围、数量上限、字段、模型去向、有效期。用途标记为 agent 声明，不作为强制限制。
4. 今天按显示的时区解析为固定起止时间；检索后应绑定具体消息集合/限制，避免后续任意扩大查询。最多 20 封须由 connector 强制执行。
5. 用户允许本次 / 调整范围 / 拒绝。调整后重新生成请求及摘要；原批准不适用变更后的请求。
6. 允许后同任务范围内不重复弹窗；超过资源、数量或时间边界需新授权。
7. 拒绝后返回明确结果，agent 可使用已有权限完成部分任务；不得自动重复弹出相同申请。
8. 完成、失败、取消均结束临时 grants；持久 grants 不变。超时由可信层独立执行。

第一版可以先采用一次一个活动任务。上下文恢复不恢复旧任务授权。新任务默认新上下文；继续旧会话应明确保留已有敏感内容。

## 06 聊天、结果与记录

聊天展示用户消息、agent 内容、简洁进度；可信授权卡由独立 UI 渲染，agent 文本不能伪造可操作控件。聊天内「以后随便访问」不能直接更改持久授权。

侧栏常驻当前权限摘要、剩余时长及管理入口。详细工具事件折叠，记录区区分请求、允许/拒绝、执行中、成功、失败、结果未知，不能把批准等同于操作完成。

结果展示摘要、生成文件入口、读取/写入资源摘要和临时权限结束状态。打开文件走可信桌面桥接并验证输出路径；不授予 agent 任意启动宿主程序的能力。审计默认只存必要元数据，避免复制邮件正文、密钥或完整敏感工具输出；保留/删除策略待实现确定。

## 07 停止、撤销和删除

| 操作 | 强制结果 | 不能承诺的效果 |
|---|---|---|
| 停止任务 | 停止后续调度并收回任务 grants | 撤回已提交的外部请求 |
| 撤销资源权限 | 阻断后续调用；关闭访问通道 | 删除已读入的上下文 |
| 读写降为只读 | 实际写入通道失效 | 撤销过去的文件修改 |
| 断开账户 | 全部 agent 失去该连接 | 未经确认的上游撤销成功 |
| 删除 agent | 停止执行、撤销授权、移除实例 | 默认删除用户的宿主目录 |

文件授权撤销/降权需处理已打开句柄，必要时终止并重建 cell；确认阻断前显示「撤销中」，失败时显示「撤销失败」并提供停止环境。账号在途请求标记可能已完成或结果未知。删除 agent 让用户选择保留/删除其工作空间和记录；绝不连带删除授权的宿主目录。

## 原型与交付边界

交互原型：[prototype/index.html](../prototype/index.html)。直接浏览器打开，或在仓库执行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory prototype` 后访问 `http://127.0.0.1:8765/`。仅向本机提供原型目录，不暴露仓库其他文件。

原型仅模拟状态，刷新重置。目录为预设示例，OAuth、安装、模型、邮件、审批执行与文件生成均未接入；不收集凭证、不访问真实文件、无外部依赖。

走查路径：初始化 → 安装 Pi → 开放「项目资料」只读及「整理结果」读写 → 连接示例 Gmail → 聊天发起任务 → 调整/批准/拒绝 → 查看结果与活动 → 修改/撤销目录或断开账户。

现有 PoC 已验证 Pi 通信、Gmail 只读、外部凭证与审批基础。桌面壳、宿主目录桥接、任务 grants、统一审计 UI、自动安装及多实例生命周期均需新增实现；尤其现有 VM 不挂载宿主目录，本 UX 不能直接通过扩大挂载实现而不重新审查边界。

后续模块讨论顺序：宿主目录访问与撤销 → 任务授权模型 → 桌面可信 UI/控制通道 → agent 安装与适配 → 账户生命周期 → 活动记录与恢复。
